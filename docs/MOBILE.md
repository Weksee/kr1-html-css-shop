# Практика 14 — оптимизация под мобильные устройства

**Скорость**
- Главное фото (2,3 МБ) на телефоне заменяется облегчённым WebP (`<picture>` + `srcset`): 23 КБ вместо 2,3 МБ. Оригинал в `images/` не изменён.
- `defer` для скриптов, `loading="lazy"` для остальных фото, `width/height` (нет скачков вёрстки), `preconnect` к CDN, `content-visibility: auto` для секций ниже экрана.
- Режим экономии трафика/2G: отключаются тяжёлые анимации.
- PWA: `manifest.webmanifest` + `sw.js` (кэш и работа без сети, установка на главный экран). Работает на localhost или хостинге по http(s), не с `file://`.

**Удобство**
- Зоны нажатия не меньше 44×44 px, шрифт полей 16 px (iOS не приближает страницу), `touch-action: manipulation`.
- Безопасные зоны «чёлки» (`env(safe-area-inset-*)`, `viewport-fit=cover`), `svh/dvh` вместо `vh`.
- Каталог: фильтры сворачиваются в кнопку «Фильтры и сортировка».
- Карточка авто: нижняя панель «цена + Купить» всегда под пальцем.
- Чат на телефоне — «нижний лист» почти на весь экран.
- Hover-эффекты отключены на сенсорных экранах (`@media (hover: none)`), вкладки кабинета прокручиваются свайпом.
- Таблицы прокручиваются внутри `table-responsive`, формы подсказывают нужную клавиатуру (`type="tel"`, `type="email"`).

**Проверка:** Chrome → F12 → значок телефона (Device Toolbar) → iPhone/Pixel; Lighthouse → Mobile → Performance/Accessibility/Best Practices.
