# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Многостраничный сайт учебного интернет-магазина на HTML и CSS.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина
без CSS-фреймворков.

## Ссылка на опубликованный проект

GitHub Pages: https://weksee.github.io/kr1-html-css-shop/

## Как посмотреть проект

1. Открыть ссылку GitHub Pages выше.
2. Или скачать репозиторий и открыть файл `index.html` в браузере.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог с фильтрами;
- `product.html` — карточка товара с таблицей характеристик;
- `order.html` — страница заявки с формой;
- `contacts.html` — контакты;
- `css/style.css` — файл стилей;
- `js/main.js` — модальное окно и обработка форм;
- `images/` — изображения;
- `.gitignore`, `README.md`.

## Используемые технологии

- HTML (семантическая разметка);
- CSS (переменные, состояния, Flexbox, Grid, позиционирование);
- JavaScript (минимально: модальное окно и форма);
- Git и GitHub, GitHub Pages.

## БЭМ-структура проекта

Основные блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — раздел страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `product-page` — страница товара;
- `product-table` — таблица характеристик;
- `catalog-layout`, `catalog-filters` — каталог и фильтры;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `faq` — вопросы и ответы;
- `site-footer` — подвал сайта;
- `to-top` — кнопка «Наверх».

Примеры: элемент `product-card__title`, модификатор `product-card--discount`.

## Позиционирование

- `position: sticky` — закреплённая шапка (`.site-header`);
- `position: relative` и `absolute` — бейджи «Хит», «Скидка», «Новинка» в карточках;
- `position: fixed` — кнопка «Наверх»;
- `z-index` — шапка и кнопка «Наверх» над содержимым.

## Самостоятельные доработки

- бейджи в карточках и несколько вариантов карточек через БЭМ-модификаторы;
- страница товара с изображением и таблицей характеристик;
- страница заявки с отдельной формой и выбором товара;
- блок «Частые вопросы» на теге `details`;
- активный пункт меню (`site-nav__link--active`);
- закреплённая шапка и кнопка «Наверх»;
- модальное окно с формой заявки и проверкой полей;
- единые CSS-переменные для цветов, отступов и скруглений.
